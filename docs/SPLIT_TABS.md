# ソースの左右表示とタブのドラッグ移動

更新: 2026-10-29。

ソース・シミュレーターのタブを、横並びのエディターグループへ配置できる。同じグループに両方の種類のタブを置くこともできる。異なるソースを左右に表示して編集したり、2つのシミュレーターを並べて比較したりできる。

## ドラッグ操作

- **タブバー上**へドロップすると、表示された挿入位置に並べ替える。別グループのタブバーへ移すこともできる。
- **グループの本文中央**へドロップすると、そのグループの末尾に移動する。
- **本文の左端・右端**へドロップすると、「左に分割」「右に分割」のガイドが表示され、その位置に新しいグループを作って移動する。
- タブが多い場合、タブバーの端にドラッグすると横にスクロールする。アプリ外へのドロップやEscapeは移動をキャンセルする。

空になったグループは閉じ、残ったグループで幅を使う。境界線のドラッグ、または境界線にフォーカスして左右キーを押すと幅を調整できる。多数のグループを作り、最小表示幅を下回る場合は、グループ全体を横スクロールできる。

タブは同じファイル・同じシミュレーターにつき1つ。今回の分割はタブの移動で、同一ソースの編集面を複製する操作は含まない。タブ1つだけのグループを、そのグループ自身の端へ分割しても配置は変わらない。

## ボタン・メニュー・キー

各グループ右上の分割アイコン、または「表示 → タブを右に分割して移動」で、選択したタブを新しい右グループへ移動できる。隣のプレビューアイコンは従来どおりアセンブル用。

| 操作 | キー |
|---|---|
| 選択タブを右に分割して移動 | Ctrl+\ |
| 左／右のグループへ移動 | Ctrl+Alt+←／→ |
| 第1〜第9グループへフォーカス | Ctrl+1〜9 |
| 現在のグループ内で次／前のタブ | Ctrl+Tab／Ctrl+Shift+Tab |
| タブバー内でタブを選択 | ←／→、Home／End |
| フォーカス中のタブを閉じる | Ctrl+W |

「表示 → グループを1つにまとめる」は、左から右のタブ順にまとめる。現在の選択タブと本文・実行状態を維持する。cmk内のファイル順序やメイン指定は、タブの並べ替えでは変更しない。

アセンブル成功時、既存の対応シミュレーターがあればそのタブを更新して選択する。新規なら対象ソースの隣の右グループへ開き、右グループがなければ作成する。

## 保持する状態

移動・並べ替え・グループ統合では、未保存本文、キャレット、選択、スクロール、Undo/Redo、診断、シミュレーターのCPU・メモリ・入力待ち・出力・実行速度・表示設定を保持する。実行中のシミュレーターを移動しても実行は継続する。

ソースはファイルごとに同じtextareaを保持する。WebViewがDOM移動時に標準のUndoを失う場合に備え、ファイルごとの補助履歴も保持する。標準Undoが使える間は従来の入力単位・IME処理を使い、失われた後は補助履歴から戻す。補助履歴は最大200状態・本文合計約1600万文字を目安に制限する。

複数のシミュレーターは個別の表示DOMを持つ。操作対象はそのタブに結び付き、COMETのSVG・入力欄・ラベル・スタック一覧も別々に更新する。アセンブラ出力と検索バーはワークスペース共通で、フォーカスしたソースを対象とする。

タブ・グループ配置・未保存本文・実行状態を再起動後に復元する機能、タブを別ウィンドウへ切り離す機能、上下分割は未実装。

## 実装

`src/tab-layout.ts`は配置と選択だけを管理し、文書やRustセッションを変更しない。`src/workbench-view.ts`はグループ・ドラッグ・ドロップガイド・境界線を描画する。ポインター操作によるドラッグで、Windowsのファイルドロップ機構に依存しない。`src/scoped-view.ts`は複数のシミュレーターのIDとラベル・SVG参照を分離する。`src/edit-history.ts`は移動後のUndo/Redoの補助履歴。

フロントエンド26テストに、並べ替えの両方向・末尾挿入、分割・空グループの除去、プレビュー先、移動後の再オープン、グループ統合、未保存文書と実行状態・cmk順序の保持、表示IDの分離、Undo/Redoの補助履歴を含む。

Rustワークスペース45テスト、TypeScript/Vite、Clippy、fmt、Tauri埋込みEXEビルドも通過。Windows実画面では3ファイルのタブ並べ替え、本文右端へのドロップによる左右表示、移動後の未保存本文とUndo、空グループの除去と幅の復元を確認した。ALPHA/BETAを各9命令で終了させ、シミュレーターを別グループへドラッグしてGR1=1/9・各出力を保持すること、片側だけのリロード・COMET切替、Ctrl+\による3グループへの分割、表示メニューによる統合も確認した。専用設定フォルダーを使った記録は`analysis/results/split-tabs/gui-verification.json`。
