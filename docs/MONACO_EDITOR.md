# Monaco Editor

ソースエディターを `monaco-editor` 0.57.0へ移行しました。APIだけの軽量版ではなく、標準の編集機能を登録するフルエントリーポイントを読み込みます。エディター本体、フォント、各Workerはアプリへ同梱し、実行時にCDNへアクセスしません。

## 操作

- Ctrl+F：検索。正規表現・大文字小文字・単語単位・選択範囲内検索に対応
- Ctrl+H：置換
- F1 / Ctrl+Shift+P：コマンドパレット。矩形選択、複数カーソル、行移動、折りたたみ、表示切替などMonacoの標準操作を実行できます
- Ctrl+Space：命令・指令・マクロ、GR0〜GR7、ラベルの補完
- F12：同じファイル内のラベル定義へ移動
- Shift+F12：同じファイル内のラベル参照を表示
- F2：同じファイル内のラベル名を変更
- Ctrl+Shift+O：ファイル内のラベル一覧
- Ctrl+/：行コメントの切替

Undo／Redo、ミニマップ、行番号、コンテキストメニュー、ホバー、START〜ENDの折りたたみ、アセンブラエラーの行表示も利用できます。ファイルメニューの保存・自動保存、タブ移動・分割、アセンブルとシミュレーターへの連携はMonacoのモデルを使います。各ファイルのエディターとモデルを維持し、通常の再描画やタブ移動で履歴を作り直しません。

## CASL IIの色分けと仕様

既存の `src/highlight.ts` のスキャナーを行単位のトークン取得関数として共通化しました。命令、指令、マクロ、レジスタ、ラベル、数値、文字列、コメントの判定をそのまま利用します。小文字の命令を認識しないこと、文字列中でもセミコロンからコメントになることなど、WCASL2向けのルールを維持しています。色は既存テーマのCSS変数から取得し、ライト／ダーク／OS同期に追従します。

位置はMonacoに合わせてUTF-16オフセットで扱います。メモリ内の改行はLF、ファイル保存は従来どおりCP932／CRLFです。日本語入力とネイティブ編集メニューの連携のため、Monacoのtextareaを使う入力経路を選択しています。表示・編集・履歴はMonacoが管理します。

ラベルの定義・参照・名前変更は同じファイル内を対象とし、複数のSTARTセクションにある同名ラベルを区別します。文字列やコメントは名前変更の対象にしません。他のファイルへの影響を判断できないSTARTのプログラム名と、定義が曖昧な名前の一括変更は行いません。新しいラベル名は標準的な英大文字・数字8文字以内に限定します。

Monaco本体の標準機能を利用する構成です。VS Codeの拡張機能ホスト、CASLの外部LSP、別ファイルにまたがるリファクタリングは含みません。

## 検証

- 既存のハイライト試験を維持し、UTF-16・セクションごとのラベル解決を追加検証
- ブラウザーで本文・未保存状態、検索／置換、分割後のUndo／Redo、命令補完、コマンドパレットを確認
- Tauriで日本語コメント、編集メニューのUndo／Redo、CP932／CRLF保存、アセンブルエラー表示を確認
- 元のHelloサンプルは10命令で正常終了。Monacoで書き換えた3語のプログラムはGR1=7で正常終了
- Tauriで既存の設定からライトへ切り替え、Monacoの背景・CASLトークン色も連動することを確認

GUIの試験では `analysis/results/monaco/config` を設定保存先として使用し、通常の設定を変更していません。
