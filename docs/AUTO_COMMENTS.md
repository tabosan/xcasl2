# 自動コメント

ソースタブ右上の吹き出しボタン「自動コメント」、メニューバーの「編集(E) → 自動コメントを追加」、またはCtrl+Shift+Cで、現在選択しているソースタブに定型コメントを付けます。命令末尾の空白を除き、タブ1個と `;` を挿入します。変更はMonacoの編集履歴に一括登録し、Ctrl+Z一回で戻せます。

設定の「自動コメントと既存のコメント」は、初期値が「既存のコメントを保持する」です。「生成対象の行のコメントを上書きする」を選んだ場合も、対象外の命令、コメントだけの行、エラー行はそのまま残します。

- アドレスは `DATA + GR2`、読み出す内容は `(DATA + GR2)`、書き込み先は `<DATA+GR2>` で表します。
- LD/LAD/ST、算術・論理演算、シフト、比較、ジャンプ、CALL、PUSH/POP、DC/DSが対象です。
- ANDの添字は実際のオペランドを使い、POPは `(SP) -> GR1, SP <- SP + 1` と記述します。
- NOP/RET/SVC、IN/OUT/RPUSH/RPOP、START/ENDにはコメントを生成しません。これらの既存コメントもそのまま保持します。
- ラベル付きDC/DSはラベル名を使います。ラベルのないDCは `<#番地>`、DSは `allocate N words at #番地` を使います。

エラー判定は既存アセンブラに従います。cmkの対象ファイルは、アセンブルと同じ登録ソースを参照して外部ラベルを検証します。解析中にシミュレーターのロード・実行や装置の入出力は行いません。

通常のアセンブルは既存の診断順序を維持します。自動コメント用の解析では、別の行に構文エラーがあっても未定義ラベルなどのリンクエラーを収集し、それらの行も変更から除外します。番地不足など行を特定できないエラーがある場合は対象ファイル全体の編集を見送ります。生成結果がCP932で200バイトを超える行にも追加しません。
