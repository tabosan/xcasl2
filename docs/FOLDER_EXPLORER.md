# フォルダーのエクスプローラー

「ファイル → フォルダーを開く…」またはエクスプローラー内の「フォルダーを開く…」で1つのフォルダーを開きます。フォルダーをクリックすると展開・折りたたみ、`.cas`をクリックすると編集タブ、`.cmk`をクリックすると既存のプロジェクト機能で開きます。大文字の拡張子も対象です。

ツリーは必要な階層だけ読み込み、フォルダーを先に並べます。左右キーで展開・折りたたみ／親子へ移動、上下キーとHome／Endで項目を移動できます。更新ボタンで外部での変更を再読込みします。フォルダーの状態は現在の起動中に保持します。

上部の「新しいファイル」「新しいフォルダー」、または右クリックメニューから、選択したフォルダー内に項目を作成します。ファイルを選択している場合はその親フォルダー内が作成先です。新しい`.cas`は空のソース、新しい`.cmk`は登録0件の有効なプロジェクトです。その他の拡張子は空ファイルとして作成・表示できますが、アプリ内での編集には対応していません。

名前はエクスプローラー内の入力欄に入力します。Enterで確定、Escapeまたは外側のクリックでキャンセルできます。同名の項目は上書きしません。使用できない名前や作成エラーは入力欄の下に表示し、そのまま修正できます。サブフォルダーを作成するとツリーへ反映し、新しい`.cas`／`.cmk`は作成後に開きます。保存先を変えてファイルを保存した場合もツリーを更新します。

右クリックの「名前の変更」またはF2で、選択したファイル・フォルダーを同じ入力欄から名前変更できます。開いているソースのパスとタブ名、配下のツリー、最近使用したファイルを更新し、本文とUndo履歴を保持します。関連するシミュレーターを停止し、再アセンブルが必要な状態にします。登録ソースのパスが変わったcmkは変更ありとなるため、プロジェクトメニューから保存してください。開いていないcmkの本文は自動変更しません。

右クリックの「削除」またはDeleteでは、確認後にWindowsのごみ箱へ移動します。未保存のソースは保存先のない編集タブに残し、関連するシミュレーターを閉じます。cmkの登録も更新します。ルートフォルダーそのものや、アプリの設定・入出力装置のファイルを含む項目は操作できません。同名への名前変更でも既存の項目を上書きしません。

削除確認は左が「ごみ箱に移動」、右が「キャンセル」です。初期フォーカスは「ごみ箱に移動」で、Enterで実行できます。Escapeでキャンセルします。「今後このメッセージを表示しない」をチェックして移動すると、次回から確認を省略し、再起動後も引き継ぎます。キャンセルした場合はこの設定を変更しません。「設定 → エクスプローラー → ファイルやフォルダーをごみ箱に移動するときに確認する」で再び有効にできます。

Windowsの操作には[IFileOperation](https://learn.microsoft.com/ja-jp/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)のごみ箱フラグを使用します。ごみ箱を使えない場合はWindowsの確認に従い、アプリ側で再帰的な完全削除へ切り替えることはありません。

ツリー、編集タブ、「開いているファイル」、プロジェクトのソースを右クリックすると「エクスプローラーで表示する」からOSのエクスプローラーでその項目を選択表示できます。ファイル・フォルダー・開閉矢印・タブの閉じるボタンはSVGで描画しています。「開いているファイル」「フォルダー」「プロジェクト」の見出しをクリックするとそれぞれ折りたため、折りたたみ状態を次回の起動時にも引き継ぎます。

フォルダーを切り替えたり閉じたりしても、編集タブ・シミュレーター・cmk登録は保持します。同じCASファイルを再度クリックしたときは既存タブを選択し、未保存の本文やUndo履歴を保ちます。cmkを切り替えるときの未保存確認、CP932／CRLF保存、20ファイルの登録制限も既存の処理を使います。フォルダーを開いた時点でファイルが自動的にcmkへ登録されることはありません。

フォルダーの読み込み・作成・名前変更・削除と、ツリーから開く項目のパスはバックエンドで選択フォルダー内か確認します。フォルダーリンクの配下へアクセスするときはリンク先も確認します。リンク自体を名前変更・削除するときはリンク先を変更せず、リンクの項目を操作します。選択したcmkから参照するソースの解決は従来のcmk仕様に従います。ファイル監視やフォルダーの次回起動時の復元は含みません。

## 検証

Rust側60件（専用一時フォルダーをごみ箱に移動する明示実行の試験1件を含む）、エディター側63件の自動テストが成功しました。作成・名前変更の同名衝突、ルート・範囲外パス、設定／装置ファイルの保護、フォルダー名変更時のキャッシュと選択、開いているソースの本文保持、Enterによる削除確認と抑制設定の保存・旧設定の移行も検証しています。

デスクトップ版ではテスト用フォルダーの選択、サブフォルダーの展開とキーボード移動、CASの編集タブ、2ファイルのcmk、空CAS・日本語フォルダー・空cmkの作成、同名ファイルの作成拒否を確認しました。同じCASを再クリックしても未保存の本文とUndo履歴を保持し、右クリックメニューからフォルダーを閉じても編集タブとcmkは残ります。記録とテスト用ファイルは`analysis/results/explorer/`です。

追加のデスクトップ検証では、インライン作成、右クリックからの名前変更、変更後のタブ名・未保存本文・Undo、重複名のインラインエラー、Escapeによる入力と削除のキャンセル、セクションの折りたたみ、OSのエクスプローラーで対象項目を選択表示する操作を確認しました。専用の設定とファイルを`analysis/results/explorer-actions/`で使用しています。
