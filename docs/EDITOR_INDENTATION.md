# インデントと略記

設定は「外観」「エディター」「アセンブル」「シミュレーター」「保存先」の目次から移動できます。「保存」で適用し、キャンセルでは変更しません。

## 既定のインデント

「エディター → 既定のインデント」に次の項目があります。設定JSONにも保存します。旧設定にはスペース・4文字・自動検出ありを補います。

- Editor: Insert Spaces：Tabキーでスペースを挿入するか。
- Editor: Tab Size：タブの表示サイズとスペースのインデント幅。1〜16の整数。
- Editor: Detect Indentation：ファイルを開く際、内容からスペース／タブと幅をMonacoで検出するか。判定材料が足りなければ既定値を使います。

既定値は次に作成・開くファイルに適用します。既に開いているモデルごとの設定は保持します。新規ファイルは空です。組み込みサンプルは現在の既定値でラベル・命令・オペランドの列を揃えます。ラベルは先頭列を維持し、列間の空白は設定幅の倍数で配置します。文字列・オペランドの中身は保持します。ユーザーが開いたファイルを自動で整形することはありません。

## 現在のファイル

ステータスバーの「スペース: 4」「タブ: 4」から次の操作ができます。

- スペースによるインデント／タブによるインデント：現在のモデルの入力方式と幅を変更。
- タブの表示サイズの変更：スペースのインデント幅を維持したまま表示幅を変更。異なる場合は「スペース: 2 (タブ: 4)」と表示。
- 内容からインデントを検出：現在の内容を再検出。
- インデントをスペースに変換／タブに変換：ファイル全体の行頭を変換。
- 末尾の空白をトリミング：各行の末尾の空白を削除。

幅の選択と変換はMonacoの標準操作を使います。一括編集はUndoで取り消せます。現在のファイルでの操作は既定設定を変更しません。タブの移動・分割でもモデルと設定を維持します。

## 略記＋Tab

行の内容が略記だけのときに展開します。通常の命令・コメント・文字列は対象外です。補完候補からも選べます。

| 略記 | 生成内容 |
| --- | --- |
| `!` | `MAIN START`、`RET`、`END` のひな形。行頭で使用 |
| `inc` | `LAD GR1,1,GR1` |
| `dec` | `LAD GR1,-1,GR1` |
| `clr` | `LAD GR1,0` |
| `inc.gr3` | `LAD GR3,1,GR3`。`dec.gr3`、`clr.gr3`なども可 |

展開後はTabで入力箇所へ移動できます。`inc`と`dec`はレジスタ名2か所を連動して編集します。インデックスにできないGR0は`inc`／`dec`の指定対象外ですが、`clr.gr0`は使えます。LADによる操作はFRを保持します。

命令の前には現在のモデルのインデントを入れます。既存の行頭空白があればそのまま使います。ひな形はCASL IIのラベルを先頭列に置き、実行可能なRETを含めています。ひな形の名前とRETはTab移動で編集できます。展開は一度のUndoで元の略記に戻せます。

## 検証

- エディター関連49件：サンプルのトークン維持、スペース／タブ・幅2/4/8での整列、略記のコンテキストとレジスタ指定を含む。
- 設定関連Rustテスト9件：旧設定の既定値、保存と再読込、不正な幅で既存ファイルを維持。
- ブラウザーで空の新規ファイル、ひな形とTab移動、略記の連動編集とUndo、幅の独立変更、内容検出、一括変換、末尾空白削除、設定目次を確認。
- 確認画面：`analysis/results/indentation/settings.png`。Tauriの設定保存はRustテストで検証。
- フロントエンドの本番ビルドとデスクトップ版のコンパイル・リンクを完了。通常のEXEはロックのため置換できず、リンク済みの最新版を`target/debug/xcasl2-indentation.exe`へコピー。元のリンク成果物とのSHA-256一致を確認。
