# COMET 配置エディター

`tools/comet-layout-editor.html` をChromeやEdgeで開いてください。HTML一つで動作し、インストールやサーバー起動は不要です。xCASL2本体と同じSVGから生成しています。

## 操作

- **ブロック**：枠・内部文字をまとめてドラッグします。接続している配線の端点は追従します。
- **文字**：ラベル・レジスタの値などを個別にドラッグします。重なって選びにくい場合は左の対象一覧から選択できます。
- **配線**：線または対象一覧で経路を選び、丸い点をドラッグして端点・折れ曲がりを移動します。選択中の線分をドラッグすると平行移動できます。「折れ曲がり追加」で迂回路を作れます。始点・終点以外の点は削除できます。
- 右側のX/Yで座標を入力できます。ブロック・文字の座標は元の位置からの移動量、配線の点はキャンバス上の座標です。
- 矢印キーで微調整、Shift併用で10倍移動します。図をクリックしてから操作してください。スナップを0にすると自由に動かせます。
- Ctrl+Z / Ctrl+Y、または上部のボタンで元に戻す・やり直しができます。
- 拡大・縮小・全体表示、キャンバスサイズ変更、ライト／ダークの見た目確認ができます。

数値は配置確認用のサンプルです。文字内容や回路の接続関係は維持し、位置と配線経路を調整します。配線は水平・垂直に描画されます。

## 調整結果を渡す

1. 「JSON書出し」で **comet-layout.json** を保存してください。
2. このチャットにそのJSONを添付してください。
3. 受け取ったJSONを検証して本体へ反映します。書き出すだけでは起動済みのxCASL2には反映されません。

「JSON読込み」で編集を再開できます。「SVG書出し」は見た目の確認・共有用です。本体への反映にはJSONを使ってください。

変更はブラウザーのローカルストレージにも下書き保存します。保存可否は下部に表示します。同じHTMLを同じブラウザーで開くと復元しますが、ブラウザーのデータ削除などで消えるため、大事な配置はJSONでも保存してください。

## 開発

- `npm run dev:layout-editor`：開発用ページを開く
- `npm run build:layout-editor`：サーバー不要のHTMLを再生成
- `npm run test:editor`：配置データの往復・検証・配線追従などのテスト

本体が読む正規の配置は `src/comet-layout.json` です。SVG本体・配線・テーマの定義を本体とエディターで共有しています。受領したJSONは `parseCometLayout` で検証したうえでこのファイルへ反映し、HTMLと本体を再ビルドします。
